# Examples Component Spec

- Section appears immediately after the hero.
- Heading: `See What You Can Create`.
- Use eight media cards with visible category, title, prompt, and `Try This Prompt` action.
- Grid is asymmetric on desktop: one wide lead card plus seven compact cards. On mobile all cards stack.
- Cards have rounded 14px corners, clipped images, a dark caption gradient, and amber action text.
